# 『Ny八股去除器』酒馆文风净化超级插件🌟 洗牌随机词池 + 四大智能句式整理 + 涩涩用词直白替换 + AI高频词进化，重塑清爽自然的阅读体验
作者：奈亚 discord：xn1060

## ✨ 洗牌真随机词池与五大内置词包
告别传统正则死板的“一对一”固定替换，彻底杜绝替换词看多了变成新八股：
**不放回洗牌随机抽取：**
- 内置 5 大类、45 组高频八股规则与 300+ 自然替换词条，每次触发像发牌一样随机抽取不同近义词，一整袋词用完前绝不重复、跨轮绝不连撞。
**老套神态与生理反应：**
- 自动净化 AI 常见的夸张五官动作与套路化生理条件反射描写，还原自然细腻的人物神态。
**网文套话与廉价香精味：**
- 自动净化陈旧的网文比喻、模式化气味描写与矫揉造作的修饰套话。
**出戏的说明书与心理学术语：**
- 自动清理旁白中破坏沉浸感的现代学科词汇与生硬的说理分析式表达。
**随手自定义替换：**
- 无需懂任何代码，直接打字即可添加专属替换词，同样支持用 `/` 填写多个替换词开启随机轮换。

## 🔞 涩涩用词直白替换
专门针对 R18 场景中令人出戏的古早网文隐喻代称进行直白化替换：
- 支持一键切换三档替换风格：**生理白描（默认） / 常用色文风 / 直白粗口风**
> 内置上下文语境识别锁：仅在带有对应部位或亲密动作语境时才触发替换
> 智能区分日常用词与特定语境，彻底杜绝误伤正常日常场景与风景描写

## 🪶 四大智能句式整理
针对 AI 最爱犯的四大句式毛病进行结构级改写：
- **绕弯否定句裁切**：自动把假否定真转折的绕弯对比句裁掉前半句假否定，直接保留后半句正面陈述  
- **极短碎句合并**：把连续单独成行的极短旁白自动连成完整句子，告别满屏单字短句刷屏  
- **高频水词配额限制**：一条回复里允许常见程度副词自然出现前 1~2 次，超出设定次数自动清理多余水词  
- **结尾老套升华清理**：自动删掉回复最末尾常见的套路收尾与抛问题句式，并智能保留前半句末尾句号

## 🛡️ 三重防误伤保护与双工作模式
精准划分清洗边界，绝不破坏角色人设与卡片功能：
**三重内容豁免：**
- 默认保护双引号内的**角色开口台词**、保护 `『...』` 包裹内容、完整保护结尾的 **尾部总结**（`<details>`）与状态栏代码块。
**静默改好与审查高亮双模式：**
- 支持 **自动帮我改好**（默认留存修改前底稿，消息底部随时可点开查看改了哪几句、或一键恢复原样，支持同楼层多分支独立切换）与 **只标出来我自己点**（荧光笔高亮标记，点哪句改哪句）。

## 🤖 独立 AI优化 与高频词识别
不配置 AI 也完全不影响插件所有本地功能正常使用；进阶玩家可单独挂载便宜/免费小模型自动治复读：
- **本地高频词扫描**：一键扫描最近几层回复中反复出现的词汇，支持一键加入限流名单或替换框  
- **独立小模型自动生成替换池**：支持配置独立 OpenAI 兼容小模型 API（不浪费聊天主模型额度），当高频复读词累计达标时，自动在后台生成 5~6 个近义替换词并排除正常剧情名词，采用 **留一换多** 模式自然分流

## 🔐 API Key 使用与隐私注意事项

### 本地功能与联网开关

本地文本清洗、替换和高频词扫描不需要 API Key。AI 优化默认关闭，密钥默认留空。

开启 AI 优化后，达到触发条件可能自动发起请求。即使自动优化关闭，点击“拉取模型”或“立即扫描当前聊天并生成替换词组”等联网操作，仍可能向配置的接口发送请求并产生费用。关闭自动优化不等于删除已保存的密钥。

### 密钥保存与传输

- API Key 随 SillyTavern 的插件设置保存。**本插件没有为密钥提供额外加密，不应将设置存储当作加密保险库。** 密码输入框的遮挡也不等于加密。
- 密钥用于向你配置的 API 服务进行身份验证。插件会尝试通过 SillyTavern 后端代理请求；必要时也可能从浏览器直接请求。因此，酒馆服务、代理和 API 服务均应可信。
- 只填写可信服务的 API 地址。远程访问酒馆和 API 时优先使用 HTTPS；陌生人提供的接口可能获取你的密钥和请求数据。
- 不要把密钥写入源码或提交到 GitHub。分享截图、设置备份、浏览器网络记录或调试日志前，检查并移除密钥；旧备份也可能保留密钥。

### AI 优化发送的数据

当前实现先在本地扫描最近的 AI 回复，再向配置的 AI 服务发送高频词分析数据和生成替换词的指令，而不是直接发送整个聊天记录。**分析词汇仍可能包含人物名字、剧情信息或其他敏感内容，不应视为匿名数据。** 拉取模型列表也会向相关服务发送认证请求。

第三方服务可能记录、保留或使用请求数据，其隐私政策、日志策略及模型训练政策由服务方决定，本插件不能保证第三方不保存数据。不希望分析数据离开酒馆环境时，请关闭自动 AI 优化，并避免点击联网操作；本地功能仍可使用。

### 推荐的安全做法

1. 为本插件使用独立、低额度或可限制权限的 API Key，并设置消费上限及账单提醒。
2. 不在不可信的共享酒馆服务或设备上保存密钥；拥有服务端、设置文件或浏览器访问权限的人可能读取它。
3. 停用时清空插件中的 API Key 并确认设置已保存；清空当前设置不会删除旧备份，也不会撤销服务商处的密钥。
4. 怀疑密钥泄露时，立即到服务商控制台撤销或轮换密钥，并检查用量记录。仅隐藏输入框或删除截图不能阻止泄露密钥继续被使用。
